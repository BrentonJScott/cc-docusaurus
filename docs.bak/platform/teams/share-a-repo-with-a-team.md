# Share a Repo With a Team

Share GitHub repositories with a Team. When you finish, Team members can select those repos when creating Capsules.

## Share repositories

1. **Open the Team**

   Open the Team that should access the repositories.

2. **Open repository sharing**

   Click **Share repositories with Team**.

3. **Select repositories**

   Turn on each repository the Team should use. Click **Share Repos**. The selected repositories appear in the wizard for Team members.

## Troubleshooting

<details>
<summary>A repository is missing from the list</summary>

Connect GitHub on **Repos** and grant access to that repository. Then open **Share repositories with Team** again.

</details>
