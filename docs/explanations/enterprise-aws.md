# Code Capsules on Your AWS

Run Code Capsules on Amazon Web Services with dedicated enterprise clusters for your organisation.

## Overview

Enterprise on AWS runs the Code Capsules platform on dedicated enterprise clusters in your organisation's own AWS infrastructure, instead of on the shared hosted platform. It's one of four enterprise options, alongside Azure, Google Cloud, and VMware.

Enterprise on AWS is coming soon.

## Why it matters

Some organisations need their applications to run on cloud infrastructure they own and control. Enterprise on AWS is for teams that want the Code Capsules way of deploying, with Spaces, Capsules, and Git-based deploys, inside their own AWS account.

:::note[Content needed]
Confirm with the product team which problems this solves for customers, such as data residency, compliance, or using existing AWS spend, and who it's aimed at.
:::

## How it works

The platform runs as a dedicated cluster for your organisation in AWS. Your teams use Code Capsules as they do today, and capsules run on that cluster instead of the hosted platform.

## When to use it

Choose the hosted platform to get started quickly with no infrastructure to run. Choose an enterprise option when your applications have to run on your organisation's own cloud.

| | Hosted platform | Enterprise on AWS |
|---|---|---|
| **Where capsules run** | Code Capsules infrastructure | Your organisation's AWS |
| **Cluster** | Shared platform | Dedicated to your organisation |
| **Availability** | Available now | Coming soon |
