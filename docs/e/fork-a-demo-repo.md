# Fork a Demo Repo

<Description />

## Prerequisites

<LinkCards>
  <LinkCard title="GitHub account" to="https://github.com/" icon="account">
    Sign up for GitHub if you don't have an account.
  </LinkCard>
</LinkCards>

## Fork the repo

<Steps>

1. **Sign in to GitHub**

   Sign in to [GitHub](https://github.com/).

2. **Open the demo repo**

   Open the demo repo named in your guide.

3. **Fork it**

   Click **Fork** at the top right of the page.

4. **Choose your account**

   Select your GitHub account as the destination and confirm. GitHub opens your fork.

</Steps>

## Troubleshooting

<Accordion>

<details>
<summary>GitHub says you've already forked the repo</summary>

You already have a fork from an earlier guide. Open it from your GitHub account and use it.

</details>

</Accordion>
