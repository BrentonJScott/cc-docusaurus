# Create a Space

A Space groups the Capsules for one project in a region. You need a Space before you can deploy a Capsule.

## Steps

1. Log in to Code Capsules and click the **Spaces** tab.
2. Click **New Space**.
3. Choose a Team. Use **Personal Team** if you're working alone, or a named Team if you're collaborating.
4. Enter a name that reminds you of the project, such as `customer-api`.
5. Choose a region close to most of your users.
6. Click **Create Space**.
