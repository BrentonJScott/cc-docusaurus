# Create a Code Capsules Account

Sign up for Code Capsules and open your Personal Team.

## Prerequisites

<DocCardList
  items={[
    {type: 'link', href: 'https://github.com/signup', label: '💻 A GitHub account', description: 'Sign up for GitHub to store the code you deploy.'},
  ]}
/>

## Create your account

1. **Sign up**

   Open Code Capsules and sign up with your name, email address, and a password.

2. **Open your Personal Team**

   After you sign up, open your **Personal Team**. You see your Personal Team dashboard.

## Troubleshooting

<details>
<summary>Sign-up says the email address is already in use</summary>

You already have an account with that email address. Log in instead.

</details>
