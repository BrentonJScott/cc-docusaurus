# Create a Code Capsules Account

Every guide needs a Code Capsules account. Follow these steps once and reuse the account across guides.

## Steps

1. Open [Code Capsules](https://www.codecapsules.io/) and click **Sign Up**.
2. Enter your details and create the account. If you already have an account, click **Log in** instead.
3. On your first login, click **Go To Personal Team**.

Code Capsules gives every account a **Personal Team**. A Team is where you manage your Spaces and Capsules.
