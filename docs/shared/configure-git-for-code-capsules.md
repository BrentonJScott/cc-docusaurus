# Configure Git for Code Capsules

Connect GitHub so Code Capsules can list your repositories when you create a Capsule.

## Steps

1. In the capsule wizard, on **Connect a Git Repository**, click **Configure Git for Code Capsules**.
2. Sign in to GitHub if asked.
3. Grant access to the repository you forked, or to all repositories.
4. Return to Code Capsules and open the **Git Repository** dropdown again. Your repository is listed.
