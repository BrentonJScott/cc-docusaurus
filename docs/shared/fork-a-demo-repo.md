# Fork a Demo Repository

Fork a Code Capsules demo repository into your GitHub account so you can deploy it.

## Prerequisites

<DocCardList
  items={[
    {type: 'link', href: 'https://github.com/signup', label: '💻 A GitHub account', description: 'Sign up for GitHub to hold your fork.'},
  ]}
/>

## Fork your demo repo

1. **Open the demo repository**

   On GitHub, open the demo repository named in the guide you're following, such as `codecapsules-io/demo-html`.

2. **Fork it**

   On the repository page, click **Fork** and create the fork under your GitHub account. GitHub opens your copy of the repository.

## Troubleshooting

<details>
<summary>GitHub says you already have a fork of the repository</summary>

You forked it earlier. Use your existing fork.

</details>
