# Fork a Demo Repository

Fork a Code Capsules demo repository into your GitHub account so you can deploy it.

## Prerequisites

<DocCardList
  items={[
    {type: 'link', href: 'https://github.com/signup', label: '💻 A GitHub account', description: 'Sign up for GitHub to hold your fork.'},
  ]}
/>

## Fork your demo repo

1. **Open the demo repository**

   Sign in to GitHub and open the demo repository named in the guide you're following, such as `https://github.com/codecapsules-io/go-demo`.

2. **Fork it**

   Click **Fork**, select your GitHub account as the **Owner**, and click **Create fork**. GitHub opens your copy of the repository.
