# Fork a Demo Repo

Code Capsules deploys from a GitHub repository you own. Fork the demo repo named in your guide to get one.

## Steps

1. Sign in to [GitHub](https://github.com/).
2. Open the demo repo named in your guide.
3. Click **Fork** at the top right of the page.
4. Select your GitHub account as the destination and confirm.
