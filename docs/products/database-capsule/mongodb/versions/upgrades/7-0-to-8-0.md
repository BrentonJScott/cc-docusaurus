# Upgrade Your MongoDB Database From 7.0 to 8.0

Upgrade a Dedicated MongoDB Capsule on Code Capsules from MongoDB 7.0 to 8.0. When you finish, the capsule is **Running** and **MongoDB Configuration** shows **8.0**.

## Upgrade your MongoDB database

1. **Open the capsule**

   On your **Space** dashboard, open your Dedicated MongoDB Capsule.

2. **Start the version change**

   On **Config**, in **MongoDB Configuration**, click **Edit**, select `8.0`, and save. Confirm the upgrade when prompted.

3. **Wait for the rollout**

   On the **Capsule** page, wait until the capsule status is **Running** and the new version is fully applied.

4. **Confirm version 8.0**

   On **Config**, **MongoDB Configuration** shows **8.0** as the active version.

## Troubleshooting

<details>
<summary>The capsule stays on Updating</summary>

The new version is still being applied. Wait for the status to return to **Running**, then check **Config** again.

</details>

<details>
<summary>Applications lose connections during upgrade</summary>

Expect short connection interruptions while status shows **Updating**. Retry application connections after the capsule returns to **Running**.

</details>
